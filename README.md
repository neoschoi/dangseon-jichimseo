### 방법 2. 터미널 실행

npm run dev

## ✨ 주요 기능 및 특징

### 1. 현실감 넘치는 3D 플립북 열람
- **자연스러운 책장 넘김**: 마우스로 모서리를 드래그하거나 클릭하여 실제 책장을 넘기듯 읽을 수 있습니다.
- **양면 / 단면 보기 전환**: 대화면에서는 양면(Spread) 모드로 실제 책처럼, 좁은 화면이나 집중 독서 시에는 단면 모드로 전환할 수 있습니다.
- **화면 가장자리 화살표**: 화면 좌우에 마우스를 올리면 나타나는 플로팅 버튼으로도 손쉽게 페이지를 넘길 수 있습니다.

### 2. 정밀하게 매핑된 목차(TOC) 사이드바
- 도서 실제 차례(차례, 책을 펴내며, 책 소개, 제1장 ~ 제6장)와 각 세부 소주제가 1:1로 연결되어 있습니다.
- 원하는 챕터나 세부 항목을 클릭하면 해당 페이지로 즉시 이동합니다.
- 목차 내 실시간 키워드 검색을 지원합니다.

### 3. 북마크(책갈피) & 개인 메모 시스템
- **북마크 (단축키 `B`)**: 중요한 페이지를 북마크해두고 사이드바에서 모아보거나 바로 이동할 수 있습니다.
- **페이지별 메모**: 각 페이지마다 나만의 전략 포인트나 아이디어를 기록할 수 있습니다.
- 브라우저 로컬 저장소(`localStorage`)에 자동 보관되어 브라우저를 닫았다가 다시 열어도 그대로 유지됩니다.

### 4. 독서 진행률 자동 기억 (이어보기)
- 마지막으로 읽던 페이지를 자동으로 기억하여, 언제 다시 접속하더라도 읽던 곳부터 바로 독서를 이어갈 수 있습니다.

### 5. 하단 썸네일 필름스트립 & 퀵 슬라이더 (단축키 `T`)
- 전체 346페이지의 미리보기 썸네일을 스크롤하며 원하는 위치를 시각적으로 빠르게 탐색할 수 있습니다.
- 북마크나 메모가 있는 페이지는 썸네일 위에 배지가 표시됩니다.

### 6. 맞춤형 독서 환경 & 줌 기능
- **3색 테마 지원**: 눈의 피로를 덜어주는 **다크 모드**, 아늑하고 따뜻한 **세피아(종이 질감) 모드**, 화사한 **라이트 모드**를 원클릭으로 전환할 수 있습니다.
- **고해상도 줌 & 패닝**: 휠이나 `+`/`-` 버튼으로 글자나 도표를 선명하게 확대하고 마우스 드래그로 자유롭게 이동할 수 있습니다.
- **전체화면 모드 (단축키 `F`)**: 방해 요소 없이 책 내용에만 온전히 몰입할 수 있습니다.

## ⌨️ 키보드 단축키 안내

| 키 | 동작 |
|:---|:---|
| `←` / `→` | 이전 / 다음 페이지 넘기기 |
| `Space` | 다음 페이지 넘기기 |
| `Home` / `End` | 책의 첫 페이지 / 마지막 페이지로 이동 |
| `F` | 전체화면 모드 켜기 / 끄기 |
| `+` / `-` | 페이지 확대 / 축소 (줌) |
| `0` | 확대 배율 원래대로 (100%) |
| `B` | 현재 페이지 북마크 토글 |
| `M` | 목차(TOC) 서랍 열기 / 닫기 |
| `T` | 하단 썸네일 필름스트립 열기 / 닫기 |
| `?` | 단축키 및 도움말 모달 열기 |
| `Esc` | 열려 있는 서랍 / 모달 닫기 (줌 초기화) |
