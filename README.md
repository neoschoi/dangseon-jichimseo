# 📖 한 권으로 끝내는 당선 지침서 - 전자책(E-Book) 및 PDF 웹 뷰어

> **스캔 원본 최적화**: 346장 WebP 변환 수록  
> **무설치 독립 실행**: Node.js나 추가 프로그램 설치 없이 Windows 기본 환경에서 즉시 실행 가능  

---

## 🚀 다른 컴퓨터에서 바로 실행하는 방법 (무설치 원클릭)

이 프로젝트는 **Node.js, Python, Git 등의 추가 프로그램을 전혀 설치하지 않아도** 어떤 Windows PC에서든 바로 실행할 수 있도록 완벽히 패키징되어 있습니다.

### 실행 방법
1. 구글 드라이브나 깃허브에서 다운로드받은 폴더로 이동합니다.
2. **`start.bat`** 파일을 더블 클릭합니다.
3. Windows 내장 PowerShell 및 웹 서버 엔진이 자동으로 구동되며, 기본 웹 브라우저(Edge, Chrome 등)가 열리면서 전자책이 즉시 펼쳐집니다.

> [!NOTE]
> * **인터넷 연결 불필요**: 오프라인 상태에서도 100% 정상 작동합니다.
> * **포트 자동 감지**: 3000번 포트가 이미 사용 중인 경우 다음 포트(3001, 3002...)로 자동 연결됩니다.
> * **종료 방법**: 실행된 검은색 콘솔 창을 닫거나 `Ctrl + C`를 누르면 서버가 종료됩니다.

## ✨ 주요 기능 및 특징

### 1. 3D 플립북 전자책 열람
- **자연스러운 책장 넘김**: 마우스로 페이지 모서리를 드래그하거나 클릭하여 실제 책장을 넘기듯 열람.
- **양면 / 단면 보기 전환**: 대화면에서는 실제 책처럼 양면(Spread) 모드, 좁은 화면에서는 단면 모드로 원클릭 전환.
- **화면 가장자리 화살표**: 화면 좌우 플로팅 화살표 버튼으로도 페이지 넘김 가능.

### 2. PDF 파일 열기 지원 (신규)
- 상단의 **[PDF 열기]** 버튼을 통해 내 컴퓨터에 보관 중인 어떤 PDF 파일이든 3D 플립북 형태로 바로 열람할 수 있습니다.
- 상단의 **[샘플 PDF]** 버튼으로 검증용 선거 가이드북(5p)을 즉시 테스트할 수 있습니다.
- 언제든 **[당선지침서]** 버튼을 누르면 원래의 346페이지 당선지침서로 복귀합니다.

### 3. 정밀하게 매핑된 목차(TOC) 사이드바
- 차례, 책을 펴내며, 책 소개, 제1장 ~ 제6장과 각 세부 소주제가 1:1로 연결되어 원하는 항목 클릭 시 해당 페이지로 즉시 이동합니다.
- 목차 내 실시간 키워드 검색을 지원합니다.

### 4. 북마크(책갈피) & 개인 메모 시스템
- **북마크 (단축키 `B`)**: 중요 페이지를 북마크해두고 사이드바에서 모아보기 가능.
- **페이지별 메모**: 각 페이지마다 나만의 전략 메모를 기록 (브라우저 로컬 저장소에 영구 보존).

### 5. 하단 썸네일 필름스트립 & 퀵 슬라이더 (단축키 `T`)
- 전체 346페이지의 미리보기 썸네일을 스크롤하며 원하는 위치를 시각적으로 빠르게 탐색할 수 있습니다.

### 6. 맞춤형 독서 환경 & 줌 기능
- **3색 테마 지원**: 눈이 편안한 **다크 모드**, 따뜻한 **세피아(종이 질감) 모드**, 화사한 **라이트 모드**.
- **고해상도 줌 & 패닝**: `+`/`-` 버튼이나 휠로 선명하게 확대하고 마우스 드래그로 자유롭게 이동.
- **전체화면 모드 (단축키 `F`)**: 책 내용에만 온전히 몰입.

## ⌨️ 키보드 단축키 안내

| 키 | 동작 |
|:---|:---|
| `←` / `→` | 이전 / 다음 페이지 넘기기 |
| `Space` | 다음 페이지 넘기기 |
| `Home` / `End` | 책의 첫 페이지 / 마지막 페이지로 이동 |
| `F` | 전체화면 모드 켜기 / 끄기 |
| `+` / `-` | 페이지 확대 / 축소 (줌) |
| `0` | 확대 배율 원래대로 (100%) |
| `B` | 현재 페이지 북마크 토글 |
| `M` | 목차(TOC) 서랍 열기 / 닫기 |
| `T` | 하단 썸네일 필름스트립 열기 / 닫기 |
| `?` | 단축키 및 도움말 모달 열기 |
| `Esc` | 열려 있는 서랍 / 모달 닫기 (줌 초기화) |
